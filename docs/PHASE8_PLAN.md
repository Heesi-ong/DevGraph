# Phase 8 (고도화) 1차 범위 — 지표·실험·성공/중단 기준

설계서 §19 Phase 8의 원칙("각 기능마다 문제 지표, 최소 실험, 성공/중단 기준을 먼저 작성")에 따른 계획이다.
1차 범위는 **(1) 운영 기반·지표 조회 경로**와 **(2) 이월된 검색/버전 항목**이다. 새 기능(Import, AI 등)은 다음 범위다.

공통 회귀 기준: NFR-01(목록·상세 p95 ≤ 500ms, 검색 ≤ 800ms, focus graph ≤ 1s, `ops/loadtest` 재측정), 보안 점검표 전 항목 유지,
backend/E2E 전체 통과. 하나라도 깨지면 해당 변경은 출시하지 않는다.

## 1. 운영 기반

| 항목 | 문제 지표 | 최소 실험 | 성공 | 중단/되돌림 |
|---|---|---|---|---|
| 지표 조회 경로 | 지표는 수집하지만 볼 수 없다(검색 0건 비율, 복사 횟수 등으로 고도화 근거를 만들 수 없음) | management 포트(8081)를 분리해 Actuator `metrics`/`prometheus`를 내부 네트워크에서만 연다. 사용량 지표(Node 생성 type별, 관계 생성, Snippet 복사)는 **횟수만**, 내용·제목·검색어·사용자 식별자는 태그로 쓰지 않는다 | 외부(nginx·호스트 포트)에서 접근 불가, 지표에 개인 지식 내용 없음(테스트), health 프로브 정상 | 지표가 개인 내용을 담거나 외부에서 열리면 즉시 비활성 |
| 시크릿 이력 스캔 | 공개 저장소 이력에 비밀이 있는지 모른다 | gitleaks로 전체 이력 스캔, CI에 추가 | 발견 0건 또는 모두 오탐 사유와 함께 allowlist | 실제 비밀 발견 시 폐기·교체 후 이력 정리 여부 결정 |
| 백업 암호화·오프사이트 | 덤프가 평문이고 같은 호스트에만 있다 | 선택 설정으로 `gpg --symmetric` AES256 암호화 + 업로드 훅. 복원 리허설이 암호화된 덤프도 처리 | 암호화 덤프로 복원 리허설 통과, 평문 덤프가 디스크에 남지 않음 | 복원 실패 시 암호화 기본값 해제 |

## 2. 이월된 검색·버전 항목

| 항목 | 문제 지표 | 최소 실험 | 성공 | 중단/되돌림 |
|---|---|---|---|---|
| Snippet diff (SNP-07) | 코드가 바뀐 근거를 보려면 두 버전을 눈으로 비교해야 한다(버전 ≥2인 Snippet 비율, 버전 원문 조회 횟수로 수요 확인) | 서버가 두 버전의 줄 단위 diff(최장 공통 부분열)를 계산해 hunks를 반환, 화면은 `+`/`-` 기호와 줄 번호로 표시(색에만 의존하지 않음) | 알려진 입력의 diff 정확성 테스트, 큰 입력(512KB)에서 상한과 시간 제한, 키보드/스크린리더에서 읽힘 | 계산 시간이 상한을 넘으면 `413`으로 거절(느린 요청이 서버를 잡지 않게) |
| 과거 버전 검색 (`scope=snippetHistory`) | 지운 줄이나 옛 코드를 찾을 방법이 없다 | `scope=snippetHistory`일 때만 과거 버전 코드 trigram 검색, 결과에 버전 번호 명시. 기본 검색은 현재 버전만(SRCH-02 유지) | 기본 검색 결과 불변(회귀 fixture), history 결과에 `versionNo` | 기본 검색에 과거 버전이 섞이면 되돌림 |
| 한국어 본문 부분 일치 | `simple` FTS는 공백 단위라 "트랜잭션을"로 쓴 본문이 "트랜잭션"으로 안 찾힌다 | 본문(앞 100,000자)에 trigram 인덱스를 추가하고 부분 일치를 후보에 포함, 랭킹은 FTS 일치보다 낮게 | 조사가 붙은 본문이 검색됨, 기존 랭킹 fixture 통과, **검색 p95 ≤ 800ms(현재 465ms) 유지** | 28k Node 부하 측정에서 목표 초과 시 인덱스/조건을 되돌리고 한국어 형태소 처리는 별도 검토 |

## 3. 이 범위에서 하지 않는 것

Import, GitHub Import, 확장 프로그램, PWA/오프라인, Graph 분석, 자동 관계 추천, 임베딩·LLM 기능. 이들은 1차 범위의 지표로 수요를 확인한 뒤 다음 범위에서 같은 형식으로 계획한다.
